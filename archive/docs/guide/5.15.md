==================================================
二、官方源码要求
================

以 PD-MORL 官方源码为准。

官方 continuous MO-TD3 的 angle 实现为：

torch.rad2deg(
    torch.acos(
        torch.clamp(
            F.cosine_similarity(w_p, Q),
            0.0,
            0.9999
        )
    )
)

因此 JAX source-faithful 版本必须等价实现：

cosine = cosine_similarity(x, y)
clipped = jnp.clip(cosine, 0.0, 0.9999)
angle = jnp.rad2deg(jnp.arccos(clipped))

要求：

- 返回单位为 degrees，不是 radians；
- clamp 范围严格为 [0.0, 0.9999]；
- 不要改成 [-1, 1]；
- 不要改成 [-1+eps, 1-eps]；
- 不要自行重标定 angle coefficient；
- 不要增加额外 normalization。

这属于：

SOURCE-FAITHFUL FIX

==================================================
三、修正 directional_angle
==========================

当前 generic directional_angle 修改为：

def directional_angle(x, y, axis=-1, eps=1e-8):
    cosine = cosine_similarity(x, y, axis=axis, eps=eps)
    cosine = jnp.clip(cosine, 0.0, 0.9999)
    return jnp.rad2deg(jnp.arccos(cosine))

不要增加 in_degrees=True/False 这种可选分支。

原因：
这个函数当前是为 PD-MORL 训练路径准备的，
应直接固定为官方源码语义，避免未来调用时误用 radians。

==================================================
四、修正 safe_norm 的 JAX autodiff 零点问题
===========================================

当前如果实现为：

norm = sqrt(sum(x**2))
return maximum(norm, eps)

请改为：

sq_sum = jnp.sum(jnp.square(x), axis=axis, keepdims=keepdims)
return jnp.sqrt(jnp.maximum(sq_sum, eps**2))

目标：

- forward 在零向量时仍返回 eps；
- 非零向量行为保持不变；
- zero vector 的 gradient 不出现 NaN。

注意：

这不是 PD-MORL 算法修改，
而是：

FRAMEWORK-ADAPTATION / JAX NUMERICAL FIX

不要把它写成“官方源码就是这么实现”。

==================================================
五、normalize_vector
====================

normalize_vector 保持：

x / safe_norm(x, keepdims=True)

但必须在代码注释和文档中明确：

normalize_vector 是 framework utility。

禁止将它自动应用到：

- preference w；
- interpolator 输出 w_p；
- Q vector；

尤其不要对 w_p 再做额外 L2 normalization。

==================================================
六、cosine_similarity
=====================

继续保持 PyTorch-style epsilon norm protection。

定义：

dot(x,y)
/
(
    safe_norm(x)
    *
    safe_norm(y)
)

不要在 cosine_similarity 内做：

- clamp；
- rad2deg；
- angle；
- extra normalization。

clamp 只属于 directional_angle。
